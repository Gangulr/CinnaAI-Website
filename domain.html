Research gap

Existing solutions

  • Manual monitoring
  • Basic irrigation systems
  • Simple disease detection tools
  • Limited robotic harvesting systems

Our proposed solution

  • IoT environmental monitoring
  • ML-based growth prediction and harvest readiness
  • AI vision-guided robotic harvesting
  • Automated cinnamon bark peeling
The gap

There is no integrated IoT, ML, AI and robotics system for cinnamon, and no automated cinnamon bark harvesting technology.

Research problem

Cinnamon cultivation relies heavily on manual experience, and nothing monitors plant growth in real time.

  • Humidity, light and soil moisture vary and are not controlled
  • Diseases are detected too late
  • Farmers cannot accurately predict harvest readiness
  • Cinnamon bark extraction is manual and inefficient

Impact

  • Low productivity
  • Inconsistent bark quality
  • High labour cost
  • Delayed harvesting decisions

Beneficiaries

  • Cinnamon farmers
  • Plantation managers
  • Agricultural researchers
  • Cinnamon export companies
  • Agricultural technology companies
  • Government agriculture sector

Research objectives

Main objective

Build one integrated system, from IoT data to ML prediction to AI vision to robotic harvesting, that supports and automates cinnamon cultivation and bark harvesting.

Specific objectives

  • Monitor the growing environment in real time and send the data to a cloud dashboard
  • Predict growth rate, bark thickness and harvest readiness, and detect disease from images
  • Detect harvest-ready bark and its peeling boundaries, and generate harvesting coordinates
  • Control a robotic machine safely to peel the bark automatically

Methodology

The workflow runs in one direction: IoT data, then ML prediction, then AI vision, then robotic machine harvesting. Each member owns one component.

Machine learning growth prediction and robotic harvest guidance

G.N. Ranaweera (IT22092656)

What it does

  • Predict cinnamon plant growth rate
  • Detect disease from plant images
  • Estimate bark thickness
  • Predict harvest readiness
  • Send harvest guidance to the robotic machine

What we built

  • Collected IoT sensor data and plant image data
  • Growth prediction model using regression and time-series methods
  • Disease detection using image classification
  • Harvest readiness output used as robot input

User needs it meets

  • Farmers need to know if a plant is ready to harvest
  • Plantation managers need prediction support to reduce manual decisions
  • Users need early disease detection
  • The robot needs a clear harvest target decision

Contribution

  • Combines sensor data and image data
  • Predicts growth, disease, bark thickness and harvest readiness
  • Turns ML predictions into robotic machine guidance
  • Explainable output: Ready, Not ready or Disease risk

IoT-driven multi-environment monitoring for robotic cinnamon cultivation

W.A.H.N. Wanasinghe (IT22092960)

What it does

  • Monitor temperature, humidity, soil moisture, UV light and white light
  • Describe the cinnamon growth chamber environment
  • Send real-time sensor data to a cloud dashboard
  • Integrate robotic machine sensors and motor feedback

What we built

  • Designed a cinnamon growth chamber prototype
  • Installed temperature, humidity, soil moisture and light sensors
  • Connected sensors to ESP32 and the Arduino environment
  • Built a real-time cloud dashboard
  • Added a robotic arm sensor interface for plant monitoring position

User needs it meets

  • Farmers need real-time plant environment monitoring
  • Plantation managers need continuous environmental data
  • Researchers need controlled environment data for growth experiments

Contribution

  • Multi-environment monitoring system
  • Cloud-based real-time dashboard
  • Sensor accuracy comparison
  • Robotic arm positioning support

AI-guided robotic machine for automated cinnamon bark harvesting

S.M.D.J.T. Samaraweera (IT22065926)

What it does

  • Detect harvest-ready bark
  • Identify bark peeling boundaries
  • Calculate harvesting coordinates
  • Control robotic machine movements
  • Automate the bark harvesting process

What we built

  • Image input from a camera or upload
  • Computer vision to detect bark boundaries
  • Target coordinates for harvesting
  • Movement instructions sent to the machine
  • Safety confirmation before the machine acts

User needs it meets

  • Farmers need faster bark harvesting
  • Plantation owners need consistent peeling quality
  • Users need less dependence on labour
  • Operators need safety control and manual override

Contribution

  • AI vision-based bark boundary detection
  • Coordinate generation for robot movement
  • Integration with the ML harvest readiness output
  • Cinnamon-specific robotic harvesting workflow
  • Start, Stop, Emergency Stop and Manual Override controls

Risks and how we handle them

RiskMitigation
Real robotic machine not fully completedUse a simulation and prototype control UI for PP1
Lack of a real cinnamon datasetUse collected sample images plus public agriculture image datasets
Sensor delay or hardware issuesUse simulated sensor data until the hardware is stable
ML accuracy may be low at firstIncrease dataset size and tune the models
Safety risk in robotic machine movementAdd manual override and emergency stop
